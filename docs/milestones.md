# Milestones

### [M0] Estructura del problema
- Objetivo: Desarrollar un modelo integral que represente los elementos clave del sistema de gestión de recursos, que permita la identificación y definición de las entidades (como usuarios, herramientas, datos disponibles) sus relaciones.
- Entregable:
Modelo que refleje el sistema de gestión, con clases y estructuras adecuadas para representar cada recurso y su relación en las HU 1 y 2
- Viabilidad:
  - Se considera viable si el modelo es claro y preciso, permitiendo que otro desarrollador entienda y continúe con el desarrollo de manera fluida.
  - Se debe validar la representación de los elementos del problema y sus relaciones a través de revisiones y feedback de otros desarrolladores.
  - Para que el modelo sea válido, debe ser flexible para permitir ajustes futuros sin romper su estructura básica.

### [M1] Definición de la métrica
- Objetivo: definición de la métrica que se utilizará para evaluar los factores según los cuales el programa devolverá una salida u otra
- Entregable: desglose del modelo de cálculo aplicado a lo especificado en el objetivo
- Viabilidad:
  - Se considera viable si el modelo es claro, preciso, y coherente, definiendo una estructura viable de implementación.
  - Se debe validar la interpretación de los elementos intervinientes y sus relaciones a través de revisiones y feedback de otros desarrolladores.

### [M2] Implementación de la extracción de datos
- Objetivo: realizar una implementación capaz de extraer los datos de eficiencia académica de los contenedores de datos de la ugr y almacenarlos de forma estructurada
- Entregable: código funcional que cumpla lo especificado en el objetivo de este milestone
- Viabilidad:
  - Se considera viable si los tests demuestran que el algoritmo respeta los requisitos de obtención definidos en el modelo y produce resultados consistentes en distintos escenarios de carga y disponibilidad.

# Milestones

### [M0] Estructura del problema
- Modelo de nuestra aplicación que represente los elementos clave del sistema de gestión de recursos y sus relaciones, además de los agregados que aparecen en las HU 1 y 2.
- Viabilidad:
  - Se considera viable cuando el modelo realizado represente de manera clara el dominio del problema que se describe en las HU 1 y 2.

### [M1] Implementación de la extracción de datos
- Módulo de código capaz de extraer los datos de eficiencia académica de los contenedores de datos de la ugr y almacenarlos de forma estructurada
- Viabilidad:
  - Se considera viable si los tests demuestran que el algoritmo respeta los requisitos de obtención definidos en el modelo y produce resultados consistentes en distintos escenarios de carga y disponibilidad.

### [M1] Implementación de la métrica
- Módulo de código capaz de aplicar la métrica del procesado de datos de la forma en la que se recoge en la HU1.
- Viabilidad:
  - Se considera viable si resuelve el problema descrito en la HU1

# Milestones

### [M0] Estructura del problema
- Desarrollar un modelo de nuestra aplicacioń que represente los elementos clave del sistema de gestión de recursos, que permita la identificación y definición de las entidades (como usuarios, herramientas, datos disponibles) y sus relaciones.
- Se entregará un modelo que refleje el sistema de gestión, con una representación de la organización y la estrutura adecuadas para exponer cada recurso y su relación en las HU 1 y 2
- Viabilidad:
  - Se considera viable si el modelo es claro y preciso, permitiendo que otro desarrollador entienda y continúe con el desarrollo de manera fluida.
  - Se debe validar la representación de los elementos del problema y sus relaciones de manera que se ajusten a la naturaleza de la que el proyecto va a requerir
  - Para que el modelo sea válido, debe ser flexible para permitir ajustes futuros sin romper su estructura básica.

### [M1] Definición de la métrica
- Definición de la métrica que se utilizará para evaluar los factores según los cuales el programa devolverá una salida u otra
- Se entregará un desglose del modelo de cálculo aplicado a lo especificado en el objetivo
- Viabilidad:
  - Se considera viable si el modelo es claro, preciso, y coherente, definiendo una estructura viable de implementación.
  - Se debe validar la interpretación de los elementos intervinientes y sus relaciones a través de revisiones y feedback de otros desarrolladores.

### [M2] Implementación de la extracción de datos
- Realizar una implementación capaz de extraer los datos de eficiencia académica de los contenedores de datos de la ugr y almacenarlos de forma estructurada
- Se entregará código funcional que cumpla lo especificado en el objetivo de este milestone
- Viabilidad:
  - Se considera viable si los tests demuestran que el algoritmo respeta los requisitos de obtención definidos en el modelo y produce resultados consistentes en distintos escenarios de carga y disponibilidad.

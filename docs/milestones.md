# Milestones

### [M0] Estructura del problema
- Desarrollar un modelo de nuestra aplicacioń que represente los elementos clave del sistema de gestión de recursos, que permita la identificación y definición de las entidades (como usuarios, herramientas, datos disponibles) y sus relaciones entre sí; además de como se representan en el propio modelo las HU 1 y 2.
- Viabilidad:
  - Se considera viable si el modelo es claro y preciso, permitiendo que otro desarrollador entienda y continúe con el desarrollo de manera fluida.
  - Se debe validar la representación de los elementos del problema y sus relaciones de manera que se ajusten a la naturaleza de la que el proyecto va a requerir

### [M1] Implementación de la extracción de datos
- Módulo de código capaz de extraer los datos de eficiencia académica de los contenedores de datos de la ugr y almacenarlos de forma estructurada
- Viabilidad:
  - Se considera viable si los tests demuestran que el algoritmo respeta los requisitos de obtención definidos en el modelo y produce resultados consistentes en distintos escenarios de carga y disponibilidad.
